# Design and Development SBA
This project is a recreation of the FLYO Data Storage Componet challenge from Frontend Mentor. The goal of this was to take a high-fidelity design and use HTML, CSS, and Bootstrap to complete it.

# User Stories
* As a user, I want to view my current storage so that I can see how much space I have left.
* As a user, I want to see how much storage space I have remaining so that I can see when I need more space.

# Users can
* View their current storage
* See remaining storage


## Features
* Bootstrap grid layout
* Custom styled storage cards
* Storage usage display
